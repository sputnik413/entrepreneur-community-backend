# 假设与待确认事项

本文档用于记录根据当前前端 Demo 推测出的产品行为，以及尚未得到明确确认的需求。

> 注意：以下内容不应被视为已确认需求。在正式实现相关功能前，需要与产品负责人进一步确认。

---

## 1. 专家对接与私信

### 当前已确认

- 用户可以按照不同领域筛选专家或企业家。
- 联系专家需要开通会员。

### 假设

用户点击“对接”后，可能会向目标专家发送联系人申请。

专家接受申请后，双方建立联系人关系，并可以通过平台进行私信交流。

可能的业务流程：

用户浏览专家
→ 点击“对接”
→ 检查会员权限
→ 发送联系人申请
→ 对方接受申请
→ 建立联系人关系
→ 开始私信

### 待确认

- “对接”是否需要对方接受？
- 对接成功后是否自动成为联系人？
- 平台是否提供站内私信功能？
- 是否只有会员可以主动发起对接？
- 会员到期后，已经建立的联系人是否仍然可以聊天？

---

## 2. 文章转发

### 当前情况

文章详情页存在“转发”功能，但当前 Demo 中尚不明确具体的转发行为。

### 可能的实现方式

1. 分享到微信、WhatsApp 等外部应用
2. 复制文章链接
3. 转发到平台内部的信息流
4. 转发时允许用户附加自己的观点

### 待确认

- “转发”具体指哪一种行为？
- 是否需要记录文章的转发次数？
- 如果支持站内转发，转发内容是否作为新的 Post？

---

## 3. 圈子可见性与加入规则

### 当前已确认

- 用户可以浏览推荐圈。
- 用户可以加入圈子。
- 普通圈成员可以发布动态。
- 圈内包含首页、成员、能力资源和活动等功能。

### 待确认

- 未加入圈子的用户是否可以查看圈内动态？
- 是否存在公开圈和私密圈？
- 加入圈子是否立即生效，还是需要管理员审核？
- 圈子是否存在管理员、圈主等不同角色？
- 管理员是否可以删除成员或删除成员发布的内容？

---

## 4. 会员体系

### 当前已确认

会员用户可以联系专家或企业家。

### 待确认

- 是否存在多个会员等级？
- 不同会员等级是否拥有不同权限？
- 是否存在会员专属文章？
- 圈子的部分功能是否需要会员权限？
- 会员是否存在有效期？
- 会员到期后如何处理已有的联系人关系？

---

## 5. 企业家身份认证

### 当前已确认

Demo 中存在通过在职证明、工牌等材料进行身份认证的功能。

### 待确认

- 在职证明和工牌验证的是“企业关联关系”，还是“企业家身份”？
- 创始人、企业所有者和企业高管是否需要不同的认证方式？
- 上传的认证材料需要保存多长时间？
- 审核完成后是否可以自动删除原始材料？
- 哪些后台角色有权查看认证材料？
- 是否允许用户遮盖员工编号、二维码等与认证无关的敏感信息？

---

## 6. 首页信息流

### 当前已确认

首页存在文章/资讯推送。

### 待确认

- 首页内容按照发布时间排序还是推荐算法排序？
- 是否根据用户加入的圈子或选择的领域进行个性化推荐？
- 文章由平台官方发布，还是普通用户也可以发布？
- 是否存在会员专属内容？

## 服务提供商企业详情页

### 假设

当前 Demo 中，点击服务提供企业后会进入相关企业家的个人主页。

考虑到企业与个人属于不同业务实体，正式系统中可能需要为服务提供商建立独立的企业详情页。

企业详情页可能包含：

- 企业名称
- 企业简介
- Logo
- 提供的服务
- 联系电话
- 联系邮箱
- 官方网站
- 地址
- 企业认证状态

用户可以通过企业详情页进一步联系服务提供商。

### 待确认

- 是否需要独立企业详情页？
- 哪些企业信息允许公开展示？
- 联系企业是否需要会员权限？
- 企业与平台用户之间如何建立关联？
